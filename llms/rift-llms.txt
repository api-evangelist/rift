# Rift

> Rift is a decentralized exchange (DEX) aggregator that routes swap orders across 20+ venues and bridges to guarantee best-price execution with no added fees. The Router API (v3, beta) provides market quoting, market order creation, and service/provider health.

## APIs
- [Rift Router API (OpenAPI)](https://raw.githubusercontent.com/api-evangelist/rift/refs/heads/main/openapi/rift-openapi.yml): 4 operations — quote, order, health, providers. Base URL https://router-gateway-v3-production.up.railway.app

## Operations
- getMarketQuote — POST /quote — best-price quote for an asset swap
- createMarketOrder — POST /order/market — create an order from a quoteId (requires idempotencyKey)
- checkRiftStatus — GET /health — API online status
- checkProviderStatus — GET /providers — execution-provider reachability

## Conventions
- Two-step flow: quote (POST /quote) then order (POST /order/market).
- Idempotency: POST /order/market requires a client-supplied idempotencyKey (16-128 chars, ^[A-Za-z0-9._:-]+$).
- Assets are addressed as Chain.Symbol (e.g. Bitcoin.BTC, Ethereum.USDC).
- amountFormat: readable | raw (default readable).
